# 移設

[English](requirements.md)

## このドキュメントについて

所有者は、ホスト名を保ったまま weblog.yamanoku.net の実行場所を移せる。保存方式は、下の一式を復元できるときだけ採る。親プロダクトは [weblog.yamanoku.net](../../product.ja.md) である。

### スコープ

- 所有者が取り出せる項目
- 復元できることを、保存方式の採否条件にすること
- アクターの秘密鍵を含む一式を、新しい実行場所へ戻すこと
- 同じホスト名を、新しい実行場所へ向けること
- バケット `gyazo-archives` を、ホストと一緒に移すこと

### スコープ外

- 取り出しファイルの物理形式。形式は下の未決事項である。
- エントリの項目、辺の規則、CLI トークン。これらは [所有者の書き込み](../owner-writing/requirements.ja.md) にある。
- 公開 HTML と、画像バイトの読み方。これらは [公開閲覧](../public-reading/requirements.ja.md) にある。
- フォロワーへの配送と、秘密鍵を公開応答とリポジトリへ出さない規則。これらは [ActivityPub](../activitypub/requirements.ja.md) にある。この機能は、秘密鍵を復元の一式に含める。その規則は置き換えない。
- 新しいホスト名。公開後のホスト名は、親プロダクトが保つ。
- カスタムドメインの料金と、ゾーンあたりの上限。数値は親プロダクトにある。

## ユーザーストーリー

### ホストを移す

所有者として、新しい実行場所へこのホストを戻したい。それによって閲覧者とフォロワーは、これまでどおり `weblog.yamanoku.net` を使える。

**受け入れ条件:**

Scenario: 一式を戻し、ホスト名を保つ場合、移設は成功する

- Given: 所有者は、アクターの秘密鍵を含む復元の一式を持っている。バケット `gyazo-archives` は複製できる。
- When: 所有者がその一式を新しい実行場所へ戻し、`weblog.yamanoku.net` の HTTPS を向け、バケットもホストと一緒に移す。
- Then: ホスト名は変わらない。不変 ID と配送済み活動の ID は、戻した値である。フォロワーが保存したこのホスト名への参照は、このホストを指したままになる。

Scenario: ホスト名を捨てる場合、フォロワーの参照は切れる

- Given: リモートのサーバが `acct:yamanoku@weblog.yamanoku.net` か、このホスト名のオブジェクト URL を保存している。
- When: 所有者が別のホスト名で一式を公開し、`weblog.yamanoku.net` を使わなくなる。
- Then: その参照は、このホストを指さない。この結果を、成功した移設には数えない。

Scenario: Gyazo の元 URL が失効した場合、バケットの実体は残る

- Given: エントリの本文は Gyazo の URL を含む。オブジェクトのバイト列はバケット `gyazo-archives` にある。
- When: その元 URL が非公開になるか、失効する。
- Then: バイト列はバケットに残る。この機能は、その失効を理由に本文を変えない。

Scenario: バケットを残して移る場合、移設は完了しない

- Given: バケット `gyazo-archives` がアーカイブのバイト列を持つ。
- When: 所有者が実行場所を移し、そのバケットを移さない。
- Then: 移設は完了しない。新しい実行場所は、この機能からそのバイト列を得ない。

## KPI

### 数値目標は置かない

- **現状値:** 無し。移設は、まだ実行していない。
- **目標値:** 無し。成功は、同じホスト名の上へ一式が戻ることとする。
- **計測方法:** 所有者は、戻した項目をデータの一式と比べる。
- **計測期間:** 移すとき。

## 機能要件

### 復元できる保存方式だけを採る

**概要:** 保存方式は、所有者が一式の全部を復元できるときだけ採る。

**入力:** ホストの保存方法の案。

**出力:** その案を採るか、採らないか。

#### 適用する条件

##### 一式

所有者は、必要なデータに書いた項目をすべて取り出せる。アクターの秘密鍵も、その一つである。一つでも戻せない案は採らない。公開応答とリポジトリは、これまでどおり秘密鍵を出さない。この扱いは [ActivityPub](../activitypub/requirements.ja.md) が定める。

#### 例外ケースでの振る舞い

##### 取り出しファイルはまだ無い

ファイル形式が未決のあいだ、この機能は取り出しファイルを書かない。採否条件は、動いている保存方式にも当てはまる。

### 移設でもホスト名を保つ

**概要:** 成功した移設は、新しい実行場所から同じホスト名を出す。

**入力:** 新しい実行場所にある、復元した一式とアクターの秘密鍵。

**出力:** その場所からの `weblog.yamanoku.net` の HTTPS。

#### 適用する条件

##### DNS

DNS の提供元は差し替えられる。ホスト名の HTTPS が、このアプリへ解決している必要がある。提供元を替えても、ホスト名は変わらない。カスタムドメインの料金とゾーンあたりの上限は、[プロダクト](../../product.ja.md) の規則である。

#### 例外ケースでの振る舞い

##### 別のホスト名

`weblog.yamanoku.net` を使っていたリモートの `acct:` とオブジェクト URL は切れる。この機能は、他のサーバが保存した写しを書き換えない。

## データ要件

### 必要なデータ

所有者が取り出せる項目は、次のとおりである。これを復元できることは、保存方式の採否条件である。

- **不変 ID:** エントリの ID。復元しても変わらない。
- **種類:** エントリの種類。
- **現在のタイトル:** 今保存しているタイトル。
- **過去のタイトル:** そのエントリが以前持っていたタイトル。
- **本文:** 保存されたプレーンテキスト。
- **公開状態:** draft または public。
- **時刻:** 保存された時刻。作成時刻と更新時刻を含む。publishedAt があるときは、それも含む。
- **Cosense のページ ID:** 外部のページ ID。保存されているときだけ含む。
- **辺:** そのエントリに保存されたリンク。
- **フォロワーのアクター URL:** 現在のフォロワーそれぞれのアクター URL。
- **配送済み活動の ID:** 配送した活動の ID。
- **アクターの秘密鍵:** 署名に使う鍵。一式に含める。公開の項目ではない。

### データ間の関係

復元の一式は、エントリ、その辺、現在のフォロワー、配送済み活動の ID、アクターの秘密鍵一つを含む。バケット `gyazo-archives` はホストと一緒に移す。バイト列を、エントリ本文の項目には含めない。

### 個人情報

フォロワーのアクター URL は、リモートのアクターを識別する。その URL は、フォロワー一覧で既に誰でも読める。秘密鍵を、フォロワーの個人情報にはしない。この機能は、鍵の新しい公開写しを出さない。

## 依存する外部サービス

- **`weblog.yamanoku.net` の DNS**
  - **関連するユーザーストーリー:** ホストを移す
  - **依存する理由:** ホスト名は、一式を戻した実行場所へ解決する必要がある。
  - **契約・利用上の判断:** 提供元は替えられる。ホスト名は保つ。料金とゾーンあたりの上限は [プロダクト](../../product.ja.md) にある。この機能は有料プランを契約しない。

- **バケット `gyazo-archives`**
  - **関連するユーザーストーリー:** ホストを移す
  - **依存する理由:** 公開ホストの画像バイトは、このバケットにある。[公開閲覧](../public-reading/requirements.ja.md) がそれを読む。
  - **契約・利用上の判断:** ホストを移すときは、このバケットを複製する。元 URL が非公開や失効になっても、バイト列は消さない。無料枠を超える保存は、親プロダクトのとおりゼロ円の対象外である。

## セキュリティ上の留意事項

署名を戻すには、アクターの秘密鍵が要る。公開応答とリポジトリには置かない。移すあいだ、所有者はこれを秘密として扱う。

一式に入るフォロワーのアクター URL は、フォロワー一覧の URL と一致する。この機能は、その一覧の外に公開の一覧を足さない。

## 未決事項

取り出しファイルの物理形式は未決である。どの形式にするかは、取り出しの保存方法を決めるときに所有者が決める。それまで、形式と拡張子とシリアライザは名付けない。

取り出せる項目は、上で決めた。復元できることを採否条件にすることも、上で決めた。形式が未決のあいだも、その決定は変えない。
