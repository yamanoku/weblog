# インストール

[English](requirements.md)

## このドキュメントについて

ログインしていない閲覧者が、このホストをアプリとしてインストールできるようにする。親プロダクトは [weblog.yamanoku.net](../../product.ja.md) である。公開エントリの閲覧は [公開閲覧](../public-reading/requirements.ja.md) に残す。

### 範囲

- すべての HTML ページから、ウェブアプリマニフェストへのリンク
- 所有者の資格情報なしで取得できる、そのマニフェスト
- 所有者の資格情報なしで取得できる、192px と 512px のアイコン
- 公開ホームを開く開始 URL
- サービスワーカーを置かないこと

### 範囲外

- オフラインでの閲覧、キャッシュ、プッシュ、バックグラウンド同期
- ページ内のインストールボタンと、OS のインストールダイアログ
- 新しい見た目。アイコンは、ページ見出しに既にある印を繰り返す
- `packages/clip` にあるブラウザ拡張のマニフェスト
- 誰が読めるか、誰が書けるか、フィード、ActivityPub、編集の流れ。これらは、既に持つ機能に残す

## ユーザーストーリー

### 公開サイトをインストールする

ログインしていない閲覧者として、このホストをインストールできるアプリとして示してほしい。インストールしたアプリから、公開ホームを開けるようにするためである。

**受入条件:**

Scenario: When a visitor opens an HTML page, the document links the manifest

- Given: 閲覧者は所有者の資格情報を持たない。
- When: 閲覧者が、このホストの HTML ページを要求する。
- Then: 応答はそのページの HTML である。文書は `rel="manifest"` でウェブアプリマニフェストをリンクする。応答はログインページではない。

Scenario: When a visitor fetches the linked manifest, the document meets the install members

- Given: 閲覧者は所有者の資格情報を持たない。マニフェストの URL は、HTML ページがリンクする URL である。
- When: 閲覧者がその URL を取得する。
- Then: 応答は JSON として解釈できる。HTML のエラーではない。認証の拒否でもない。`name` または `short_name` がある。`start_url` は `scope` の内側にある。`display` は `standalone`、`fullscreen`、`minimal-ui`、`window-controls-overlay` のいずれかである。`display_override` が同じ値でもよい。値 `browser` は使わない。`prefer_related_applications` は無いか、false である。`icons` は 192px と 512px のアイコンを含む。各 `purpose` は `any` を含む。`purpose` の省略も許す。

Scenario: When a visitor fetches a required icon, the bytes match the declared size

- Given: 閲覧者は所有者の資格情報を持たない。マニフェストは 192px のアイコンと 512px のアイコンを名付ける。
- When: 閲覧者が、それぞれのアイコン URL を取得する。
- Then: 各応答は PNG、WebP、SVG のいずれかの画像バイト列である。PNG または WebP の幅と高さは、マニフェストが宣言した大きさである。SVG は空でない SVG 文書である。本文は HTML でも JSON でもない。

Scenario: When a visitor opens the start URL, the public home is returned

- Given: 閲覧者は所有者の資格情報を持たない。マニフェストの `start_url` はこのホスト上にあり、`scope` の内側にある。
- When: 閲覧者がその開始 URL を要求する。
- Then: 応答は公開ホーム、つまり配送対象エントリの一覧である。ログインページでも、編集ページでもない。

Scenario: When a title would use the manifest path, the manifest stays the manifest

- Given: タイトルの比較キーが、マニフェストのパスである。
- When: 未認証のクライアントがそのパスを要求する。
- Then: 応答はマニフェスト文書である。そのタイトルに閲覧用パスは無い。タイトルは正規 URL に残る。

## 機能要求

### マニフェストをリンクする

**概要:** すべての HTML ページが、一つのマニフェストを指す。最初の HTML 応答にリンクを含める。このホストの HTML ページ間を後から移動しても、リンクは残る。

**入力:** HTML ページへの要求。所有者の資格情報は任意である。

**出力:** そのページの HTML。`rel="manifest"` を含む。

#### 適用条件

##### マニフェストの URL は一つ

リンク先はこのホスト上にある。すべての HTML ページで同じ URL である。ブラウザ拡張のマニフェストではない。

#### 例外

##### HTML ページでない応答

フィード、画像バイト列、Activity Streams の文書には、このリンクを足さない。本文は、それらの機能が既に返す文書のままである。

### マニフェストとアイコンを返す

**概要:** マニフェストと、必要な二つのアイコンは、公開の文書である。所有者の資格情報は要らない。資格情報を送っても、編集ページには置き換わらない。

**入力:** マニフェスト URL の GET、またはそのマニフェストが名付けるアイコン URL の GET。

**出力:** マニフェストの JSON、またはアイコンのバイト列。

#### 適用条件

##### マニフェストの項目

マニフェストは `name` または `short_name` を持つ。`start_url` は公開ホーム `/` に解決され、`scope` の内側にある。`scope` は `/` である。`display` は `standalone` である。`prefer_related_applications` は無い。`icons` は 192px の PNG と 512px の PNG を名付ける。各アイコンの `purpose` は `any` を含む。

##### アイコンのバイト列

必要な各アイコンは PNG である。幅と高さは、マニフェストが名付けた大きさと等しい。絵は、ページ見出しに既に描いてある印である。

#### 例外

##### 要求に資格情報が付く

所有者の Cookie や Access ヘッダは、マニフェストもアイコンのバイト列も変えない。編集 URL のゲートは、所有者の書き込みが既に適用するゲートのままである。

## データ要求

### 必要なデータ

- **ウェブアプリマニフェスト:** インストールできるアプリの公開の説明。名前、開始 URL、範囲、表示モード、アイコンの URL を持つ。この機能は、エントリのデータベースへは保存しない。
- **アイコン:** 見出しの印を 192px と 512px にしたもの。この機能は、エントリとしては保存しない。

### 関係

一つのマニフェストが、二つのアイコンを名付ける。`start_url` は公開ホームを指す。マニフェストはエントリ ID を指さない。

### 個人情報

なし。マニフェストとアイコンはサイトを名付ける。閲覧者は名付けない。

## 外部サービスへの依存

なし。文書は、今の Worker が返す。この機能は、有料の Cloudflare 製品も、二つ目の Worker も足さない。

## セキュリティ上の考慮

マニフェストとアイコンは、資格情報なしで読める。トークンも、非公開のエントリも含まない。これらを公開しても、編集 URL は開かない。

## 未決事項

なし。ブラウザがインストールダイアログを出すかは、そのブラウザ自身の利用規則による。この機能は、そのダイアログを決めない。
